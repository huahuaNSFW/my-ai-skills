# 文锚 · Style Anchor

[**中文版**](README.zh-CN.md)　|　[**English**](README.en.md)　|　[返回首页](../README.md)

**已有风格提示词的约束补丁。**

你已经写好了自己的风格提示词：它决定作品的声音、气质与表达方式。文锚为它补充执行边界，处理含糊、冲突及过度执行，让你的 AI 在保留原审美的前提下使用这套风格。

文锚接收 **原风格提示词 + 可选创作任务**。只提供原提示词时，输出可追加的最小补丁；同时提供任务时，应用补丁后交付作品。原风格提示词保留，只有你明确要求时才输出合并版。

## 交给你的 AI 读取

把下面内容发给具备仓库或网页读取能力的 AI，再附上你自己的风格提示词：

```text
请读取这个仓库：https://github.com/huahuaNSFW/my-ai-skills
先读 README.md，再读 skills/style-anchor/SKILL.md，
然后完整读取 skills/style-anchor/references/rules.zh-CN.md。

加载「文锚」作为我现有风格提示词的约束补丁。
保留我的审美、声音和明确禁令。只追加解决实际问题所需的约束。
没有创作任务时只给可追加补丁；有创作任务时直接交付作品。
文件读取失败时告诉我缺少哪个文件，不要假装已加载。

【我的原风格提示词】
在这里粘贴你已经写好的风格提示词。

【本次创作任务，可选】
在这里写任务；仅需要补丁时可以不填。
```

可读取文件的 AI 应先确认原提示词已提供，再按技能入口读取规则。只贴仓库链接且未给原提示词时，AI 应先索取原提示词。

## AI 应如何使用本库

1. 读取技能入口，选择并完整读取一份语言规则。
2. 将用户原提示词作为待约束的风格配置，保留原文。
3. 判断是否有含糊、冲突、过度执行或内容损失风险；只加相关约束。
4. 原审美与用户当前明确要求优先于补丁默认建议。
5. 按用户请求输出补丁或创作结果，避免默认输出一套新风格。
6. 无法读取规则文件时，请用户提供内容。不会访问网页的工具可由用户粘贴入口和中文规则全文。

## 示例：保留华丽，约束堆砌

**原提示词**
> 写得华丽，有古典感，多用意象。

**文锚追加补丁**
> 保留华丽、古典的语感。意象应与当前场景或情绪有关；缺乏新含义和节奏作用的连续意象可删减。清晰交代本任务中必须表达的信息，不强制每句使用意象。

这条补丁仅对应示例的执行风险。对冷峻、口语化、碎片化等风格，需要依据各自的原提示词确定约束。
